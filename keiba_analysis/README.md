# 競馬自動分析システム v1.0

毎週末のメインレース（10R以降）を自動収集・分析し、期待値ベースで推奨馬を抽出するシステムです。

## 必要なもの

- **Python 3.8 以上**（無料）
- **インターネット接続**（データ取得に必要）

### Pythonのインストール方法

#### Windows の場合

1. https://www.python.org/downloads/ にアクセス
2. 「Download Python 3.x.x」ボタンをクリック
3. ダウンロードしたファイルを実行
4. **「Add Python to PATH」にチェックを入れる**（重要）
5. 「Install Now」をクリック

#### Mac の場合

ターミナルを開いて以下を実行：

```bash
# Homebrewがない場合は先にインストール
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Pythonをインストール
brew install python3
```

## セットアップ手順

### Windows

1. `setup.bat` をダブルクリック
2. 自動的に必要なライブラリがインストールされます
3. 「セットアップが完了しました！」と表示されれば完了

### Mac / Linux

1. ターミナルを開く
2. このフォルダに移動（例: `cd ~/keiba_analysis`）
3. 以下を実行：

```bash
chmod +x setup.sh run_analysis.sh
./setup.sh
```

## 使い方

### 起動方法

- **Windows**: `run_analysis.bat` をダブルクリック
- **Mac/Linux**: ターミナルで `./run_analysis.sh` を実行

### メニュー画面

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  競馬自動分析システム v1.0
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 今週末のレースを分析
  2. 特定のレースを分析
  3. オッズを更新して再計算
  4. 週次レポートを表示
  5. 設定変更
  6. 終了
```

### 各メニューの説明

#### 1. 今週末のレースを分析

- 次の土曜・日曜のメインレース（10R〜12R）を一括分析
- データ収集 → 分析 → Excelレポート生成を自動実行
- 結果はコンソールに表示され、Excelファイルも生成されます

#### 2. 特定のレースを分析

- 日付を指定して特定の日のレースを分析
- 過去の日付も指定可能（データが残っている場合）

#### 3. オッズを更新して再計算

- レース直前にオッズを再取得
- 期待値を再計算して更新レポートを生成
- 期待値が高い馬が出現した場合はアラート表示

#### 4. 週次レポートを表示

- 累積的中率・回収率を表示
- 週ごとのパフォーマンス推移を確認

#### 5. 設定変更

- 予算額の変更
- 対象レース番号の変更
- リクエスト間隔の調整

## 出力されるレポート

レポートは `output/reports/` フォルダに保存されます。

**ファイル名**: `競馬分析レポート_YYYYMMDD.xlsx`

### シート構成

| シート名 | 内容 |
|----------|------|
| サマリー | 全レースの推奨馬一覧と信頼度 |
| (各レース名) | レースごとの全馬評価詳細 |
| 詳細データ | 各項目別のスコア詳細 |
| 投資戦略 | 予算配分と推奨ベット一覧 |
| 統計ダッシュボード | 累積パフォーマンスと推移グラフ |

### 評価の見方

| 記号 | 意味 | R/R比 |
|------|------|-------|
| ◎本命 | 強く推奨 | 1.5以上 |
| ○対抗 | 推奨 | 1.2〜1.5 |
| △検討 | 検討可 | 1.0〜1.2 |
| ×回避 | 回避推奨 | 1.0未満 |

## 分析の仕組み

### 基礎スコアリング（6項目、各10点満点）

1. **前走成績評価** - 直近のレース結果
2. **コース適性** - 同じ競馬場・同じ馬場での勝率
3. **距離適性** - 同距離での勝率
4. **騎手評価** - 騎手のコース別勝率
5. **枠順評価** - 枠番ごとの統計勝率
6. **血統評価** - 父馬の条件別勝率

### 期待値計算

```
期待値 = (推定勝率 × 単勝オッズ) - 1
```

- 期待値がプラス = 統計的に有利な馬券
- 期待値が大きいほど有利

### リスクリワード比

```
R/R比 = 期待リターン / 期待損失
```

- 1.5以上が投資対象として推奨

### 展開予想

- 各馬の脚質（逃げ/先行/差し/追込）を過去データから推定
- ペース予想を行い、展開の有利不利を評価
- ペースに応じたボーナス/ペナルティをスコアに反映

## トラブルシューティング

### 「Pythonが見つかりません」と表示される

- Pythonをインストールしたか確認してください
- Windows: インストール時に「Add Python to PATH」にチェックを入れたか確認
- PCを再起動してからもう一度試してください

### 「ライブラリのインストールに失敗しました」

以下のコマンドを手動で実行してください：

```bash
# Windows
pip install requests beautifulsoup4 openpyxl schedule

# Mac/Linux
pip3 install requests beautifulsoup4 openpyxl schedule
```

### 「レースデータを取得できません」

- インターネット接続を確認してください
- レース開催日以外の日付を指定していないか確認してください
- Webサイトの構造が変更された可能性があります。しばらく待ってから再試行してください

### レポートが文字化けする

- Excelで開く際、UTF-8エンコーディングで開いてください
- LibreOfficeをお使いの場合は問題なく表示されます

### データベースエラー

`data/keiba.db` を削除してから `setup.bat`（または `setup.sh`）を再実行してください。

## 注意事項

- 本システムは統計的な分析に基づく参考情報を提供するものです
- 馬券の購入は自己責任で行ってください
- データの取得にはサイトへのアクセスが伴います。過度な使用は控えてください
- 分析結果は過去のデータに基づくものであり、将来の結果を保証するものではありません
